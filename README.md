# Mfinelli Supermario

## How do I install these formulae?

`brew install mfinelli/supermario/<formula>`

Or `brew tap mfinelli/supermario` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "mfinelli/supermario"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
